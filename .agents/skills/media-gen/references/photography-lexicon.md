# Photography lexicon

Prompt as if describing a real photograph. Official FLUX guides:

- https://docs.bfl.ml/guides/prompting_summary.md
- https://docs.bfl.ml/guides/prompting_unified_reference.md

Name camera, lens, aperture, lighting, surface, and mood in prose — not keyword lists. Lighting has the highest impact.
